# 时间安全的 LSTM 基线

这个可选模块用于补充深度学习能力，同时保持与主实验一致的时间审计口径。

## 实验定义

- 输入：每条商品序列截至截点的 56 天日需求；
- 标签：截点之后 14 天的需求总量；
- 模型：共享参数的单变量 LSTM，按每个窗口的历史均值缩放并使用 `log1p` 变换；
- 切分：训练序列的标签结束日期不晚于验证截点；
- 基线：同一验证样本上的 Last-14；
- 默认范围：全国口径历史需求最高的 200 条序列、最后一个滚动验证折。

窗口尺度归一化让不同销量等级的商品共享一个全局模型，同时保留每条序列自己的
数量级。默认实验是计算成本可控的诊断，不与 README 中覆盖全部库存单元的六折
LightGBM 结果直接比较。只有在扩大到完整滚动验证、加入分位输出并验证库存成本
后，LSTM 才适合成为 Newsvendor 与 MILP 的正式上游候选模型。

## 运行

~~~bash
python -m pip install -r requirements-deep-learning.txt
python scripts/run_lstm_baseline.py
~~~

输出包括逐序列预测、训练元数据、模型权重和聚合报告。模型权重与原始数据不提交
到 Git；聚合报告可以在重跑后审阅。
