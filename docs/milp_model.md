# 多仓库存协调 MILP

对商品 `i` 和区域仓 `s`，设：

- `x[i,s]`：分配到区域仓的库存量，按 0.1 件离散并取整数；
- `u[i,s]`：相对区域仓独立 Newsvendor 建议的补少偏差，连续非负；
- `v[i,s]`：相对区域仓独立 Newsvendor 建议的补多偏差，连续非负。

目标函数最小化：

`sum(A[i,s] * u[i,s] + B[i,s] * v[i,s])`

其中 `A`、`B` 来自公开数据的补少与补多成本。核心约束为：

1. `target[i,s] - x[i,s] = u[i,s] - v[i,s]`；
2. 每个商品满足 `sum_s x[i,s] = national_target[i]`；
3. 若调用方提供仓容，则满足 `sum_i x[i,s] <= capacity[s]`；
4. 所有库存分配非负，`x` 为整数。

整数分配变量与连续偏差变量共同构成 MILP。默认公开数据实验不启用仓容约束，因为天池文件没有给出仓容；仓容参数只用于显式输入的场景分析，不能写成真实企业容量。

同一确定性目标同时保留 CP-SAT 实现，单元测试核对两种建模范式的总量约束和目标值。随机场景协调仍使用独立的 CP-SAT 模型。
